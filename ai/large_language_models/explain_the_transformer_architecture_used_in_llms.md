Modern LLMs use the decoder-only Transformer architecture, which differs from the original encoder-decoder design. The decoder-only architecture generates text autoregressively—predicting one token at a time, with each prediction conditioned on all previous tokens. The architecture consists of stacked layers of masked self-attention and feed-forward networks, with residual connections and layer normalization.

Each layer has two main components. Masked multi-head self-attention allows each token to attend to all previous tokens but not future ones (using a causal mask). This maintains the autoregressive property needed for generation. The feed-forward network (FFN) processes each position independently through two linear transformations with a non-linearity (typically GELU or SwiGLU) between them: `FFN(x) = W2 * activation(W1 * x + b1) + b2`. The FFN is where much of the model's factual knowledge is stored.

Positional encoding provides sequence order information. Original Transformers used sinusoidal encodings, but modern LLMs use Rotary Position Embeddings (RoPE) which encode relative positions through rotation in the complex plane, allowing better generalization to longer sequences. Some models use ALiBi (Attention with Linear Biases) which adds position-dependent biases to attention scores.

Scaling techniques are critical for training stability. RMSNorm (pre-normalization) is applied before attention and FFN blocks. Residual connections allow gradients to flow directly through the network. Learning rate warmup and cosine scheduling optimize training dynamics. The combination of these techniques enables training models with hundreds of billions of parameters on thousands of GPUs. Architecture variants include PaLM (parallel attention and FFN), LLaMA (RMSNorm, SwiGLU, RoPE), and Mixture of Experts (MoE) models which activate only a subset of parameters per token for efficiency.
