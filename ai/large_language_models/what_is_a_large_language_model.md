A Large Language Model (LLM) is a neural network trained on vast amounts of text data to understand and generate human language. LLMs are typically Transformer-based architectures with billions of parameters (GPT-4 reportedly has over a trillion parameters). They are pre-trained using self-supervised learning—predicting the next token in a sequence—which teaches them grammar, facts, reasoning patterns, and world knowledge from the training corpus.

LLMs exhibit emergent abilities that smaller models lack: in-context learning (learning from examples in the prompt), chain-of-thought reasoning (breaking down complex problems step-by-step), and instruction following (performing tasks described in natural language). These capabilities emerge at scale—models below a certain size threshold simply cannot perform these tasks, regardless of training.

The training pipeline typically involves three stages. Pre-training on massive text corpora (trillions of tokens) teaches general language understanding. Supervised fine-tuning (SFT) on curated instruction-response pairs teaches the model to follow instructions. Reinforcement Learning from Human Feedback (RLHF) aligns the model with human preferences, improving helpfulness and safety while reducing harmful outputs.

LLMs power a wide range of applications: chatbots and virtual assistants, code generation, content creation, translation, summarization, question answering, and more. They can be accessed via APIs (OpenAI, Anthropic, Google) or run locally (LLaMA, Mistral, Phi). Key limitations include hallucinations (generating plausible but false information), context window limits, training data cutoffs, and inability to access real-time information. Despite these limitations, LLMs represent the most significant advance in AI capability in decades, fundamentally changing how developers build applications.
