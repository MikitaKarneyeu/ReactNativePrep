Cross-validation is a resampling technique used to evaluate model performance and detect overfitting by training and testing on different data subsets. The most common form is k-fold cross-validation: the dataset is split into k equal folds, the model is trained k times, each time using k-1 folds for training and the remaining fold for validation. The final performance metric is the average across all k runs.

Cross-validation provides a more reliable performance estimate than a single train-test split. With a single split, the evaluation depends heavily on which data points end up in each set—lucky or unlucky splits can give misleading results. K-fold reduces this randomness by testing on every data point exactly once. Common values are k=5 or k=10, balancing computational cost with reliable estimation.

Stratified k-fold ensures each fold has approximately the same class distribution as the full dataset, which is critical for imbalanced classification problems. Leave-one-out cross-validation (LOOCV) uses k equal to the number of samples—each sample is tested individually. This has low bias but high variance and is computationally expensive for large datasets. Time-series data requires special handling—standard k-fold would leak future information into training, so rolling-window or expanding-window cross-validation is used.

Cross-validation is used for model selection (comparing different algorithms), hyperparameter tuning (finding optimal settings), and feature selection (evaluating which features improve performance). In scikit-learn, `GridSearchCV` and `RandomizedSearchCV` combine cross-validation with hyperparameter search. Nested cross-validation uses an outer loop for performance estimation and an inner loop for hyperparameter tuning, providing an unbiased estimate of the tuned model's performance.
