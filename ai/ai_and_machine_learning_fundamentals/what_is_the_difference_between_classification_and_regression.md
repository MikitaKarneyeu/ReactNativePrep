Classification and regression are the two primary types of supervised learning, distinguished by their output types. Classification predicts discrete categories or classes—the output is a label from a finite set. Binary classification has two classes (spam/not-spam, fraud/not-fraud), while multi-class classification handles multiple categories (digit recognition, sentiment analysis). The model outputs a probability distribution over classes, and the predicted class is typically the one with the highest probability.

Regression predicts continuous numerical values. Examples include predicting house prices, temperature, stock prices, or click-through rates. The output is a real number on a continuous scale. Common regression algorithms include linear regression, polynomial regression, SVR (Support Vector Regression), and gradient boosting regressors. Evaluation metrics differ significantly: classification uses accuracy, precision, recall, F1-score, and AUC-ROC, while regression uses MSE, RMSE, MAE, and R-squared.

Some algorithms can handle both tasks. Decision trees and random forests can be used for classification or regression depending on the target variable. Neural networks are similarly flexible—the architecture and loss function determine the task. For classification, the output layer uses softmax (multi-class) or sigmoid (binary) activation with cross-entropy loss. For regression, the output layer is typically linear with MSE loss.

The choice between classification and regression depends on the problem formulation. Sometimes a regression problem can be reframed as classification (predicting price ranges instead of exact prices) and vice versa. Multi-output tasks may combine both—predicting both the category of an object and its bounding box coordinates (classification + regression) is common in object detection.
