BERT (Bidirectional Encoder Representations from Transformers) is a pre-trained language model developed by Google in 2018. It uses the Transformer encoder architecture to create bidirectional contextual representations of text. BERT is pre-trained on two objectives: Masked Language Modeling (MLM), where 15% of tokens are randomly masked and the model predicts them using surrounding context, and Next Sentence Prediction (NSP), where the model predicts whether two sentences are consecutive.

GPT (Generative Pre-trained Transformer) uses the Transformer decoder architecture with causal (left-to-right) attention. Each token can only attend to previous tokens, not future ones. GPT is pre-trained to predict the next token in a sequence—autoregressive language modeling. This makes GPT naturally suited for text generation tasks.

Key differences: BERT is bidirectional—it sees the entire context in both directions when making predictions, making it excellent for understanding tasks (classification, NER, question answering). GPT is unidirectional—it only sees left context during pre-training, making it better for generation tasks but requiring more work for understanding tasks. BERT uses fine-tuning with task-specific heads (classification layers), while GPT uses prompting and in-context learning (especially at scale).

In practice, BERT excels at tasks requiring deep understanding of text: sentiment analysis, named entity recognition, semantic similarity, extractive question answering. GPT excels at generation tasks: text completion, summarization, translation, creative writing, and conversational AI. At large scale (GPT-3, GPT-4), the generative approach becomes extremely versatile, handling understanding tasks through prompting. Modern practice favors decoder-only models (GPT-style) for general-purpose LLMs, while encoder models (BERT-style) remain popular for specific NLU tasks and embeddings.
