Transfer learning in NLP is the practice of pre-training a model on a large corpus of text, then fine-tuning it on a specific downstream task. This approach leverages knowledge learned from vast amounts of text data to improve performance on tasks with limited labeled data. The key insight is that language understanding—grammar, semantics, world knowledge, reasoning patterns—can be learned from unlabeled text and transferred to specific applications.

The pre-training phase uses self-supervised objectives on massive text corpora. BERT-style models use masked language modeling (predicting masked tokens), while GPT-style models use autoregressive next-token prediction. These objectives require no human labeling—the data itself provides supervision. Pre-training captures syntactic and semantic knowledge, common sense reasoning, and factual knowledge about the world.

Fine-tuning adapts the pre-trained model to a specific task by adding a task-specific head (e.g., a classification layer) and training on labeled task data. Because the model already understands language, fine-tuning requires relatively few labeled examples and converges quickly. A BERT model fine-tuned on a few thousand labeled examples for sentiment analysis can outperform models trained from scratch on millions of examples.

Modern transfer learning has evolved beyond simple fine-tuning. Prompt-based learning formats tasks as text generation, allowing a single pre-trained model to handle many tasks without task-specific heads. Instruction tuning fine-tunes on diverse tasks described in natural language, improving zero-shot generalization. RLHF (Reinforcement Learning from Human Feedback) aligns models with human preferences. In practice, developers rarely train from scratch—they start with pre-trained models (BERT, GPT, LLaMA, Mistral) and either fine-tune for their specific use case or use them directly via prompting. This dramatically reduces the data, compute, and expertise required to build effective NLP systems.
