Gradient descent is an optimization algorithm that iteratively adjusts model parameters to minimize a loss function by moving in the direction of steepest descent (negative gradient). The update rule is: `θ = θ - α * ∇L(θ)`, where θ are parameters, α is the learning rate, and ∇L is the gradient of the loss. The algorithm computes gradients using backpropagation and repeats until convergence.

Batch gradient descent computes the gradient using the entire training dataset before making an update. This provides a stable, accurate gradient direction but is computationally expensive for large datasets—it requires processing all samples before a single weight update. Stochastic Gradient Descent (SGD) computes the gradient using a single random sample per update. It's much faster per iteration and can escape local minima due to its noisy updates, but the high variance makes convergence less stable.

Mini-batch gradient descent is the practical compromise—it computes gradients on small batches (32, 64, 128, 256 samples) and updates weights after each batch. This balances the stability of batch gradient descent with the efficiency of SGD. Batch size is a hyperparameter: smaller batches add regularization through noise, larger batches provide more stable gradients and better utilize GPU parallelism. Most deep learning uses mini-batch SGD with batch sizes of 32-512.

Advanced optimizers improve on basic SGD. Momentum accumulates a velocity vector to accelerate convergence and smooth oscillations: `v = β*v + ∇L; θ = θ - α*v`. AdaGrad adapts the learning rate per parameter, shrinking it for frequently updated parameters. RMSprop modifies AdaGrad to use a moving average of squared gradients, preventing the learning rate from decaying too aggressively. Adam (Adaptive Moment Estimation) combines momentum and RMSprop—it maintains both first-moment (mean) and second-moment (variance) estimates of gradients. Adam is the default optimizer for most deep learning tasks due to its robust convergence properties.
