Activation functions introduce non-linearity into neural networks, enabling them to learn complex patterns. Without activation functions, a multi-layer network would collapse into a single linear transformation—no matter how many layers you add, the output would be a linear function of the input. Non-linear activations allow networks to approximate arbitrary functions, which is why they're essential for learning complex relationships in data.

Common activation functions include ReLU (Rectified Linear Unit): `f(x) = max(0, x)`. It's computationally efficient, doesn't saturate for positive values, and has become the default for hidden layers. However, it suffers from "dying Reurons"—neurons that output zero for all inputs and stop learning. Variants like Leaky ReLU (`f(x) = x if x > 0, else 0.01x`) and ELU address this. Sigmoid `f(x) = 1/(1+e^(-x))` outputs values between 0 and 1, useful for binary classification output layers but prone to vanishing gradients in hidden layers. Tanh `f(x) = (e^x - e^(-x))/(e^x + e^(-x))` outputs between -1 and 1, centering data around zero.

The output layer activation depends on the task. Softmax converts logits into a probability distribution for multi-class classification: `softmax(z_i) = e^(z_i) / Σ(e^(z_j))`. Sigmoid is used for binary classification or multi-label tasks. Linear activation (no transformation) is used for regression tasks where the output can be any real number.

The choice of activation function impacts training dynamics significantly. ReLU and its variants are preferred for hidden layers due to computational efficiency and reduced vanishing gradient issues. GELU (Gaussian Error Linear Unit) is used in Transformers and BERT. Swish (`x * sigmoid(x)`) has shown improvements in some architectures. The key considerations are: non-linearity (required for hidden layers), differentiability (needed for gradient-based optimization), gradient magnitude (avoiding vanishing or exploding gradients), and computational cost (especially important for mobile deployment).
