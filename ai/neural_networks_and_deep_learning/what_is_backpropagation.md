Backpropagation (backward propagation of errors) is the algorithm used to compute gradients of the loss function with respect to each weight in a neural network. It's the core learning mechanism that enables neural networks to learn from data. The algorithm works by applying the chain rule of calculus to compute how much each weight contributed to the overall error, allowing the network to adjust weights to reduce the error.

The process has two phases. Forward pass: input data flows through the network, each layer computes its output, and the final layer produces a prediction. The loss function quantifies the error between the prediction and the true label. Backward pass: starting from the loss, gradients are computed layer by layer moving backward through the network. Each layer's gradient depends on the gradient from the layer above and the local gradient of its own operation. The chain rule is applied at each step: `∂Loss/∂w = ∂Loss/∂output * ∂output/∂w`.

The computed gradients are then used by an optimizer to update weights. The simplest update rule is gradient descent: `w_new = w_old - learning_rate * gradient`. More sophisticated optimizers like Adam, RMSprop, and AdaGrad adapt the learning rate per parameter and incorporate momentum for faster convergence. The learning rate is critical—too high causes instability, too low causes slow convergence.

Backpropagation through time (BPTT) is the extension for recurrent neural networks, where gradients flow backward through both layers and time steps. This can lead to vanishing or exploding gradients in long sequences, which is why architectures like LSTM and GRU were designed with gating mechanisms to control gradient flow. Modern frameworks (PyTorch, TensorFlow) implement automatic differentiation, which automatically computes gradients through arbitrary computational graphs, making backpropagation transparent to developers.
