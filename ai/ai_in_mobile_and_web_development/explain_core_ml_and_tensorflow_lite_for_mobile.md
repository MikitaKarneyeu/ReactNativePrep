Core ML is Apple's machine learning framework for deploying models on iOS, macOS, watchOS, and tvOS devices. It supports models from various training frameworks (TensorFlow, PyTorch, scikit-learn) converted to the .mlmodel format using coremltools. Core ML automatically optimizes models for Apple hardware, leveraging the CPU, GPU, and Neural Engine for maximum performance and energy efficiency. It integrates seamlessly with iOS frameworks like Vision (image analysis), Natural Language (text processing), and Speech.

TensorFlow Lite (TFLite) is Google's framework for deploying ML models on mobile (Android, iOS), embedded systems, and IoT devices. Models are converted from TensorFlow to the optimized .tflite format, which reduces model size and improves inference speed. TFLite supports quantization (int8, float16) for smaller models and faster inference. It provides delegates for hardware acceleration—GPU delegate for OpenGL/Metal, NNAPI delegate for Android's Neural Networks API, and Hexagon delegate for Qualcomm DSPs.

Key differences: Core ML is Apple-only but offers the best performance on Apple devices through deep hardware integration. TFLite is cross-platform (Android, iOS, embedded Linux) but requires more manual optimization. Core ML handles model optimization automatically; TFLite requires explicit quantization and optimization steps. Core ML integrates with iOS development tools (Xcode, Swift); TFLite uses Java/Kotlin for Android and C++ for embedded.

For developers choosing between them: use Core ML for iOS-only apps where you want seamless integration with Apple's ecosystem. Use TFLite for Android apps or cross-platform requirements. Both support common model architectures—image classification, object detection, text classification, style transfer, and pose estimation. In practice, many cross-platform apps use both: Core ML for iOS builds and TFLite for Android builds, with the same model converted to both formats. Emerging alternatives include ONNX Runtime Mobile (cross-platform) and MediaPipe (Google's framework for real-time vision pipelines).
