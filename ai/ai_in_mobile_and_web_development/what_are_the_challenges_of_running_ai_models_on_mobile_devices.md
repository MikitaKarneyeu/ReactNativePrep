Running AI models on mobile devices faces several constraints that don't exist in cloud environments. Memory is the primary limitation—mobile devices have 4-8GB of RAM shared between the OS, apps, and the model. A model that uses 2GB of RAM may not fit on many devices. Model optimization techniques like quantization (float32 to int8 reduces size by 4x), pruning (removing unnecessary weights), and knowledge distillation (training a smaller student model) are essential.

Compute power is limited compared to cloud GPUs. Mobile CPUs and GPUs are designed for efficiency, not raw throughput. Inference that takes 10ms on a GPU may take 100-500ms on a mobile device. The Neural Processing Unit (NPU) or Neural Engine on modern phones (Apple's A-series, Qualcomm's Hexagon) provides hardware acceleration but has limited model support. Developers must optimize models for the target hardware and test on representative devices.

Battery consumption is a critical concern. ML inference uses CPU/GPU continuously, draining battery faster than typical app operations. Running a model for real-time camera processing can reduce battery life significantly. Developers should implement adaptive processing—reduce inference frequency when the battery is low, pause processing when the app is backgrounded, and use the most energy-efficient hardware available (NPU over GPU over CPU).

Model size affects download size and storage. A 100MB model adds significant bulk to an app download. Solutions include downloading models on first use, using smaller quantized models, and supporting model updates without full app updates. Cross-platform development is challenging—Core ML models don't work on Android and vice versa, requiring separate model conversion and optimization for each platform. Testing is complex—model behavior can vary across devices, OS versions, and hardware generations. In practice, start with cloud inference for prototyping, then optimize for on-device as you identify the most critical features and gather real-world performance data.
