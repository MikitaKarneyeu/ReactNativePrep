Object detection identifies and localizes objects within an image by outputting bounding boxes and class labels for each detected object. Unlike image classification (which assigns a single label to the entire image), detection answers "what objects are in this image and where are they?" This combines classification (what is it?) with localization (where is it?).

Two-stage detectors like Faster R-CNN first generate region proposals (areas likely to contain objects) using a Region Proposal Network (RPN), then classify each proposed region and refine its bounding box. This two-step process is accurate but slower, making it suitable for applications where accuracy is more important than speed.

One-stage detectors like YOLO (You Only Look Once) and SSD (Single Shot Detector) process the entire image in a single pass, directly predicting bounding boxes and class probabilities. YOLO divides the image into a grid and predicts multiple bounding boxes per grid cell. This is much faster than two-stage detectors, enabling real-time detection at 30+ FPS. Modern YOLO versions (YOLOv8, YOLOv9) achieve state-of-the-art accuracy while maintaining real-time speed.

Anchor-free detectors like CenterNet and FCOS detect objects by predicting key points (like object centers) rather than predefined anchor boxes. This simplifies the architecture and handles objects of unusual aspect ratios better. Transformer-based detectors (DETR) use attention mechanisms to detect objects without hand-designed components like anchor boxes or NMS.

Evaluation uses mean Average Precision (mAP)—the area under the precision-recall curve averaged across classes. IoU (Intersection over Union) measures how well predicted boxes overlap with ground truth. An IoU threshold of 0.5 is common—predictions with IoU ≥ 0.5 are considered correct. In practice, object detection powers autonomous driving (detecting pedestrians, vehicles, traffic signs), surveillance (person detection, activity recognition), retail (shelf analysis, checkout-free stores), medical imaging (tumor detection), and mobile applications (AR, visual search).
