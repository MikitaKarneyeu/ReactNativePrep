Image classification assigns a single label (or probability distribution over labels) to an entire image. The input is an image, and the output is a class—"cat," "dog," "car." The model determines the dominant content of the image. Architectures like ResNet, VGG, EfficientNet, and Vision Transformers (ViT) are designed for classification. The final layer typically uses softmax to output probabilities for each class.

Semantic segmentation classifies every pixel in the image, producing a mask where each pixel is assigned a class label. The output has the same spatial dimensions as the input, with a class label per pixel. This enables understanding the exact boundaries and regions of objects. Architectures like FCN (Fully Convolutional Network), U-Net, and DeepLab use encoder-decoder structures—the encoder extracts features, and the decoder upsamples to produce pixel-level predictions. Applications include autonomous driving (road, sidewalk, building, sky), medical imaging (organ boundaries, tumor regions), and satellite imagery analysis.

Instance segmentation combines object detection with semantic segmentation—it identifies individual object instances and produces a separate mask for each one. Two people in an image would get separate masks, even though they're the same class. Mask R-CNN extends Faster R-CNN by adding a mask prediction branch to each detected object. This is used when you need to count or track individual objects.

Panoptic segmentation unifies semantic and instance segmentation, labeling every pixel with both a class and an instance ID. Background classes (sky, road) get semantic labels, while thing classes (people, cars) get instance labels. Panoptic FPN and Mask2Former are common architectures.

The choice depends on the task: classification for "what is in this image?", semantic segmentation for "what regions are what?", instance segmentation for "how many individual objects and where?", and panoptic segmentation for complete scene understanding. In practice, segmentation requires more training data (pixel-level annotations are expensive) and more compute than classification. Transfer learning with pre-trained encoders significantly reduces data requirements. U-Net with a pre-trained backbone is a strong default for medical and scientific segmentation tasks.
