Transformers are a neural network architecture introduced in the 2017 paper "Attention Is All You Need" by Vaswani et al. They replaced recurrent and convolutional architectures for most NLP tasks by using self-attention mechanisms to process entire sequences in parallel. The architecture consists of an encoder (processing input) and decoder (generating output), each made up of multi-head attention layers and feed-forward networks with residual connections and layer normalization.

The core innovation is self-attention, which computes relationships between all positions in a sequence simultaneously. For each position, the model computes query (Q), key (K), and value (V) vectors by multiplying the input by learned weight matrices. Attention scores are computed as: `Attention(Q, K, V) = softmax(QK^T / √d_k) * V`. This allows each token to attend to all other tokens, capturing long-range dependencies regardless of distance. Multi-head attention runs multiple attention computations in parallel with different learned projections, allowing the model to capture different types of relationships.

The encoder processes the input sequence through multiple layers of self-attention and feed-forward networks. Each layer applies multi-head self-attention, adds a residual connection, applies layer normalization, then passes through a feed-forward network with another residual connection and normalization. The decoder is similar but includes cross-attention to the encoder output and causal masking to prevent attending to future tokens during generation.

Transformers revolutionized NLP because they process sequences in parallel (unlike sequential RNNs), capture long-range dependencies effectively, and scale to very large models. BERT uses the encoder for understanding tasks, GPT uses the decoder for generation, and T5 uses both. The architecture extends to vision (ViT), audio (Whisper), and multimodal tasks. The main limitation is quadratic memory complexity O(n²) with sequence length, motivating efficient variants like Linformer, Performer, and Flash Attention.
