Zero-shot learning is the ability of a model to perform a task it was never explicitly trained on, using only the task description in natural language. For example, asking an LLM "Classify this review as positive or negative: 'The food was amazing!'" without providing any examples. The model leverages its pre-training knowledge to understand the task and produce an appropriate response. Zero-shot capability emerges at sufficient model scale—smaller models fail at zero-shot tasks that larger models handle easily.

Few-shot learning provides a small number of examples (typically 2-5) in the prompt to demonstrate the expected input-output pattern. For instance: "Translate English to French: 'Hello' -> 'Bonjour', 'Thank you' -> 'Merci', 'Goodbye' ->" The model learns the pattern from these examples and applies it to the new input. Few-shot learning is more reliable than zero-shot for tasks with specific formatting requirements or domain-specific conventions.

The distinction between zero-shot and few-shot is important for system design. Zero-shot is simpler—you don't need to curate examples—and works well for common tasks the model has seen during pre-training. Few-shot is more reliable for specialized tasks, unusual formats, or when you need consistent output structure. The examples act as a "soft" form of training, adjusting the model's behavior without weight updates.

These capabilities are enabled by in-context learning, an emergent property of large Transformer models. The model effectively "learns" from the examples in the prompt without gradient updates. This is distinct from traditional few-shot learning in ML, which typically involves meta-learning algorithms that explicitly optimize for learning from few examples. In practice, the choice depends on task complexity, reliability requirements, and latency constraints. Zero-shot is preferred for simple tasks where you want minimal prompt overhead. Few-shot is used when consistency and accuracy are critical. Both approaches benefit from clear task descriptions and well-formatted prompts.
