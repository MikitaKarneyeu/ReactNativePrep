Supervised learning trains models on labeled data—each input has a corresponding correct output. The model learns to map inputs to outputs by minimizing prediction error. Common tasks include classification (predicting categories like spam/not-spam) and regression (predicting continuous values like house prices). Algorithms include linear regression, logistic regression, support vector machines, random forests, and neural networks. The key requirement is a high-quality labeled dataset, which can be expensive to create.

Unsupervised learning works with unlabeled data, discovering hidden patterns and structures without predefined outputs. Common techniques include clustering (K-means, DBSCAN, hierarchical clustering) for grouping similar data points, dimensionality reduction (PCA, t-SNE, UMAP) for compressing features, and anomaly detection for finding outliers. Unsupervised learning is useful for exploratory data analysis, customer segmentation, and feature learning. Since no labels are required, it can leverage vast amounts of raw data.

Reinforcement learning (RL) trains agents to make sequential decisions by interacting with an environment. The agent takes actions, receives rewards or penalties, and learns a policy that maximizes cumulative reward over time. Key concepts include states, actions, rewards, and the exploration-exploitation tradeoff. RL has achieved superhuman performance in games (AlphaGo, Atari), robotics, and is the foundation of RLHF (Reinforcement Learning from Human Feedback) used to align large language models. Algorithms include Q-learning, SARSA, Policy Gradient methods, and PPO.
