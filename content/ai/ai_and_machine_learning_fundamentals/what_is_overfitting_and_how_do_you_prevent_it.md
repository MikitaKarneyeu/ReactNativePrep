Overfitting occurs when a model learns the training data too well, including noise and irrelevant patterns, resulting in excellent training performance but poor generalization to unseen data. The model essentially memorizes the training set rather than learning underlying patterns. Signs include high training accuracy but significantly lower validation/test accuracy, and a large gap between training and validation loss curves.

Several techniques prevent overfitting. Regularization adds a penalty to the loss function based on model complexity—L1 regularization (Lasso) adds absolute value of weights, encouraging sparsity, while L2 regularization (Ridge) adds squared weights, encouraging small distributed weights. Dropout randomly deactivates a fraction of neurons during training, forcing the network to learn redundant representations. Early stopping monitors validation loss and stops training when it starts increasing while training loss continues decreasing.

Data augmentation artificially increases training set diversity by applying transformations (rotations, flips, crops for images; synonym replacement, back-translation for text). This exposes the model to more variations without collecting new data. Cross-validation, particularly k-fold, provides a more reliable estimate of model performance and helps detect overfitting by testing on multiple validation splits.

Model complexity control is another lever. Simpler models (fewer parameters, shallower trees, lower polynomial degrees) are less prone to overfitting. For neural networks, reducing the number of layers or neurons helps. Ensemble methods like bagging (Random Forest) reduce overfitting by averaging multiple models trained on different data subsets. Boosting methods require careful tuning to avoid overfitting. In practice, a combination of these techniques yields the best results—dropout + regularization + early stopping is a common recipe for neural networks.
