OpenAI, Anthropic, and Google are the three major LLM API providers, each with distinct characteristics. OpenAI offers the GPT family (GPT-4, GPT-4o, GPT-3.5-turbo) through the OpenAI API. It has the largest ecosystem, most mature SDKs, and widest adoption. The API supports chat completions, function calling, vision, DALL-E image generation, and Whisper speech recognition. Pricing is per-token with different rates for input/output tokens.

Anthropic offers Claude models (Claude 3.5 Sonnet, Claude 3 Opus, Claude 3 Haiku) through the Anthropic API. Claude is known for strong reasoning, long context windows (up to 200K tokens), and safety-focused design. The API structure is similar to OpenAI's but with differences in message formatting and system prompt handling. Anthropic emphasizes safety and constitutional AI principles. Claude excels at analysis, writing, and complex reasoning tasks.

Google offers Gemini models (Gemini Pro, Gemini Ultra) through the Google AI Studio and Vertex AI APIs. Gemini integrates with Google's ecosystem and supports multimodal inputs (text, images, audio, video). Vertex AI provides enterprise features like grounding with Google Search, custom tuning, and integration with Google Cloud services. Google also offers PaLM and Gemma (open-source) models.

Key API differences: OpenAI uses `messages` array with `role` and `content` fields. Anthropic uses a similar structure but separates system prompts from messages. Google's API has a different structure with `contents` and `parts`. Function calling implementations vary—OpenAI's is the most mature. Streaming, JSON mode, and vision capabilities are supported by all three but with different implementations. Pricing varies significantly—Claude Haiku and GPT-3.5-turbo are cheap for simple tasks, while GPT-4 and Claude Opus are more expensive but capable. In practice, many applications support multiple providers with abstraction layers or use tools like LiteLLM that provide a unified API.
