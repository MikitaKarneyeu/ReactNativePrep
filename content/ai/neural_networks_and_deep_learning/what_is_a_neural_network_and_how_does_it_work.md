A neural network is a computational model inspired by biological neural networks, consisting of interconnected nodes (neurons) organized in layers. Each neuron receives inputs, applies weights and a bias, then passes the result through an activation function to produce an output. A typical network has an input layer (receiving raw features), one or more hidden layers (learning representations), and an output layer (producing predictions).

Forward propagation is how the network computes predictions. Input data flows through the network layer by layer. Each neuron computes a weighted sum of its inputs, adds a bias term, and applies a non-linear activation function: `output = activation(Σ(weight_i * input_i) + bias)`. The weights and biases are the learnable parameters that the network optimizes during training. Deep networks with multiple hidden layers can learn hierarchical features—early layers learn simple patterns (edges, textures), while deeper layers learn complex concepts (objects, faces).

Training uses backpropagation and gradient descent. The network makes a prediction, computes the loss (error) using a loss function, then backpropagates gradients through the network to compute how each weight contributed to the error. Weights are updated using an optimizer (SGD, Adam, etc.) to minimize the loss. This process repeats over many iterations (epochs) until the network learns to make accurate predictions.

Neural networks are universal function approximators—a sufficiently large network can theoretically learn any continuous function. In practice, architecture design matters enormously. Convolutional layers exploit spatial structure in images, recurrent layers handle sequential data, attention mechanisms capture long-range dependencies. Modern architectures like Transformers have revolutionized NLP and are the foundation of large language models. The choice of architecture, activation functions, loss function, and optimizer all significantly impact performance.
